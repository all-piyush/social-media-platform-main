# Social Media Platform (MERN Stack)
## Overview
- This is a full-stack social media platform built using the MERN stack.
- Users can create posts, like posts, and add comments.

## Live Demo: 
Frontend: https://social-media-platform-frontend-eta.vercel.app/ 
## Features
- User Authentication (Login/Register)
- Create Posts (with optional image)
- Like / Unlike Posts
- Comment on Posts
- View All Posts
- View My Posts

## Tech Stack
- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB Atlas
